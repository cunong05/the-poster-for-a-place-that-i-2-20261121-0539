A travel poster for a place that does not exist. Lumaris is an invented archipelago where the tide runs through glass: one lighthouse built of sea-glass stands on a rocky point above a turquoise lagoon at golden sunset, a lone sailboat crossing water lit gold. The name is set large across the top in cream serif capitals, with the subtitle "THE GLASS-TIDE ISLES" beneath it — nothing else written on the poster.

## How to run

```sh
node main.ts
```

The program copies `entry.png` to `/output/entry.png` (set `MAKEFUN_OUTPUT_DIR` to change the destination). It checks the poster first — real PNG, exactly 1024×1024, at most 1 MiB — and confirms the copy byte for byte, so repeated runs always produce the same file.
